# CV_Parser

Contributors right now : Tselmeg, Justin
<hr>

<b> A web app that reads CVs and turns them into structured data, to later rate and tailor them against job descriptions. </b>

# Running the frontend

### Place these commands into the bash or cmd

cd frontend

npm install

npm run dev

### Then open http://localhost:5173 in your browser

<hr>

<h1> Things to download for llm to work as it is hosted from the web</h1>

<b> Place this commands into the bash or cmd </b>

pip install llama-cpp-python huggingface-hub

pip install llama-cpp-python --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cpu
